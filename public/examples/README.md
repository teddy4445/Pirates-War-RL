# Example files

These are teaching and production-import fixtures used by the implemented platform.

`default-config.json` supplies proposed defaults. `twin-harbors.map.json` supplies a continuous polygon map with eight spawn slots per side, water delivery zones, land home posts, and two neutral shoreline placement sites. Validate it with the implemented collision/connectivity code before release.

For a script ZIP: copy `manifest-script.json` to `manifest.json` and include `agent-script.js` as `agent.js`. The script chases flags and can fire, but has no general obstacle planner. It is a teaching starter, not a promised strong AI.

`tfjs-constant-forward.agent.zip` is a real restricted TF.js Layers package generated by `npm run examples:build`. It contains `manifest.json`, `agent.js`, `model/model.json`, and a weight shard. The model maps batches of 64 input features to 22 scores and is intentionally untrained. `manifest-tfjs.json` and `neural-agent.js` are its readable source inputs.

`constant-forward.agent.json` is already a complete text-only Dense model package. It has 64 inputs, 22 outputs, zero weights, and a bias selecting action 7 (forward/straight/no fire). It is intentionally UNTRAINED. Its purpose is to exercise schema validation and numerical inference, not demonstrate learning.

Run the example and import checks:

```bash
python tools/check_bundle.py
node tools/test_examples.cjs
```

The production QuickJS, Dense, restricted TF.js, training, tournament, and replay paths are covered by Vitest and Playwright. `python-dqn-smoke.agent.json` is a genuine short-run export with provenance in the adjacent metrics file; it proves compatibility, not policy strength.
